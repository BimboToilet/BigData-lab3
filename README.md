# Запуск
`docker compose up -d` - запустит все необходимые контейнеры в правильной последовательности, исполнит пайплайн обработки (bronze, silver, gold).  
  
Для дальнейшей работы необходимо перейти на `localhost:8888` в браузере и посмотреть/запустить пример работы с обработанными данными (обучение моделей) в Jupyter Notebook.  
  
Результат работы пайплайна обучения моделей можно посмотреть в MLFlow (`localhost:5000`), там же можно сравнить метрики/модели, посмотреть на артефакты (графики), связанные с моделями.  
  
## Пример запроса к данным
<img width="962" height="75" alt="Запрос к данным" src="https://github.com/user-attachments/assets/01fa4838-ad68-4451-b01a-1ecd75628505" />  
  
Здесь приложен пример запроса к трём столбцам в данных. Он показывает именно план выполнения запроса.  
  
Благодаря тому, что таблица партиционирована по году и месяцу, Polars не стал сканировать всё хранилище. Он сразу обратился к конкретной папке. Это экономит время и ресурсы, так как исключаются данные за все остальные годы и месяцы.  
  
Строка `PROJECT 4/13 COLUMNS` показывает, что из 13 доступных в таблице колонок Polars прочитает с диска только 4. В традиционных форматах пришлось бы читать всю строку целиком. На выходе мы получим всего 3 колонки (`simple π 3/3`).  
  
Секция `SELECTION` содержит фильтры из запроса: `Origin == "JFK"` и `Year == 2024`. Эти фильтры применяются в момент чтения файла. Polars не загружает данные в память, чтобы потом их отфильтровать, а отбрасывает ненужные строки максимально рано.
